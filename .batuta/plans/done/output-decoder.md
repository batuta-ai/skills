## Decisions and context

Conventional commits. Routing and ACP metadata stay as they are. Core applies `limit_regex` and `usage_regex` to the decoded text, and decoders emit exactly these lines for provider failures (core#128): `provider error: api_error_status <n>: <text>` and `provider limit: <rateLimitType> <status> resetsAt <ts>` (claude), `provider error: <message>` (codex, where the message is the provider's JSON body), `provider error: <name> <statusCode>: <message>` (opencode), `provider error: <error>` (agy). Anchor every new alternative on the `provider ` prefix: a bare `rate limit` alternative once matched an executor's own prose and made the loop wait (learnings, 2026-09-22). Keep the cycle packet within 9500 tokens (`tests/skills/check.sh`); if the new lines push it over, shorten adapter notes rather than the lines. Real outputs of each format are in core `executor/testdata/stream/` and `executor/testdata/stream/errors/`.
