## Decisions and context

Conventional commits. Routing, the ACP metadata and every `readonly` line stay as they are.

**Task 1.** Core tokenizes the `run` line once without a shell, honours single and double quotes, and substitutes only the known placeholders (`{brief}`, `{brief_file}`, `{prompt}`, `{cwd}`, `{model}`, `{effort}`, `{model_flags}`, `{cwd_flag}`), so the JSON braces inside the single-quoted `--settings` value pass through unchanged. If `tests/skills/check.sh` rejects unknown `{…}` sequences in a run line, teach it to ignore braces inside a single-quoted token rather than changing the JSON. Without the `Edit(./**)` allow rule, `acceptEdits` asked for permission on a new file in 2 of 5 probe runs and headless claude stopped; with it, 4 of 4 passed. With `--force`, cursor-agent's sandbox did not contain anything; without it, the edit tool refused outside writes and the sandbox blocked outside shell writes.
